Glossary

Terms are added when the task that needs them starts. Current terms come from Tasks 01 to 09.

Adapter
Code that wraps an existing model to change its form — module types, tensor layouts, interface — without changing its weights or meaning, so it can deploy on a target runtime. Qualcomm's Qwen adapter lives in qai_hub_models/models/qwen3_0_6b/.
adb (Android Debug Bridge)
The standard Android command-line tool: push and pull move files, shell runs commands on the device. In QDC it talks to a remote adb server through an SSH tunnel.
AdaScale
An AIMET method that learns per-weight scaling on real data instead of taking the max, by matching each quantized block's output to its float output. Runs on a CUDA GPU before calibration in Qualcomm's Qwen3 recipe.
AIMET
Qualcomm's AI Model Efficiency Toolkit for quantization and model optimization.
AI Hub job
One unit of work on Qualcomm AI Hub: compile, link, profile, or inference. Each job gets an ID and runs on a chosen hosted device.
AI Hub Workbench
Qualcomm's managed service for compiling, testing, profiling, and running models on hosted devices.
Asynchronous execution
The GPU queues work and the CPU call returns before the work is done. Honest timing needs a synchronize call, such as torch.mps.synchronize(), before reading the clock.
Autoregressive
Generating one token at a time, feeding each chosen token back as input for the next step. All chat LLM generation works this way.
Backend
The lower-level runtime that executes model operations on a compute unit.
Bundle (GenieX QAIRT)
The published package for an LLM: QNN context binaries plus the runtime configs and tokenizer that GenieX needs to run them. Built per chipset.
Calibration
Measuring activation value ranges by running sample data through a fake-quantized model. AIMET does it with compute_encodings; the result becomes the encodings.
Context binary
A compiled QNN graph artifact prepared for a target Qualcomm platform.
Decode
The repeated one-token forward pass during generation. Input shape [1, 1]; history comes from the KV cache, which grows by one slot per step.
Embedding
A lookup table that maps each token id to a learned vector. In Qwen3-0.6B it has 151,936 rows and 1,024 columns.
Encodings
The stored quantization parameters — a scale (and optional offset) for every quantized tensor. Saved as model.encodings in a quantized checkpoint.
EOS token
The special token id that marks the end of a message. Generation stops when the model picks it. For Qwen3 chat it is <|im_end|>, id 151645.
Fake quantization
Snapping values to the integer grid but keeping them as floats, so the accuracy of the real integer version can be predicted without special hardware. AIMET's QuantSim works this way.
GenieX
A public generative-AI interface that coordinates model execution through supported backends.
geniex-bench
GenieX's benchmark command. Runs the full prefill and decode loop and reports TTFT, prefill tokens/s, and decode tokens/s as JSON cells.
GQA (grouped-query attention)
Attention where several query heads share one key/value head. Qwen3-0.6B uses 16 query heads and 8 key/value heads, so 2 query heads share each K/V pair. This halves the KV cache.
Greedy decoding
Generation that always picks the single highest-scoring next token. Deterministic: the same input gives the same output.
Group (quantization)
The set of weights that share one scale: the whole tensor (per-tensor), one output row (per-channel), or a small block inside a row (per-group). Finer groups mean less error and more stored scales.
Host
The CPU-side program that drives a compiled graph: tokenization, RoPE tables, mask building, cache writes, token selection. Work moved to the host does not need to compile for the NPU.
Hosted device
A physical phone or board in Qualcomm's lab that AI Hub jobs run on. Shared, queued, and free to use with an account.
Initializer
A constant tensor stored inside an ONNX graph — mainly the model weights. Initializers are not inputs, so the declared input list shows only what a caller must supply.
Input spec
Qualcomm's name for a graph contract: an ordered mapping from input name to shape and dtype, produced by get_input_spec in the adapter classes.
JSONL
A text file with one JSON object per line. Benchmark results append as rows; each line parses on its own.
KV cache
Stored key and value tensors for all past tokens, kept so each new token does not recompute them. It grows with every generated token.
LM head
The final layer that turns the last hidden state into one score per vocabulary token. In Qwen3-0.6B its weight is the embedding table, reused.
Logits
The raw, unnormalized scores the model outputs — one number per vocabulary token — before any softmax or sampling.
Monkey patch
Replacing a class or function in another module at runtime by assigning over its name. Qualcomm's adapter uses it to swap Hugging Face internals for NPU-friendly versions without forking the library.
NPU
Hardware specialized for neural-network computation.
ONNX
Open Neural Network Exchange: a file format for a frozen operator graph with named, typed, shaped inputs and outputs. A common exchange step before hardware-specific compilation.
ONNX Runtime
The engine (onnxruntime) that loads an ONNX file and executes it. It enforces the graph's declared shapes and dtypes.
Opset
The versioned dictionary of ONNX operators a graph is written against. This project exports with opset 17.
Outlier (weight or activation)
A value far larger than its neighbors. It stretches the max-based scale, so all normal values in its group round coarsely.
Part (model split)
One deployed piece of a model that was cut for memory or workload reasons. Parts run in sequence on the device. Qwen3-0.6B ships as two: the embedding, then the 28 layers plus the LM head.
Prefill
The single forward pass over the whole prompt that fills the KV cache. Input shape [1, P] for P prompt tokens. Its time is what "time to first token" measures.
Profile job
An AI Hub job that loads a compiled model on a hosted device and measures load time, inference time, memory, and per-layer compute-unit placement.
QAIRT
Qualcomm AI Runtime, the deployment and runtime suite also described in current public material as Qualcomm AI Engine Direct.
QDC
Qualcomm Device Cloud, which provides remote access to Qualcomm hardware.
QDC interactive session
A live reservation of a real device in Qualcomm's lab. You connect through an SSH tunnel and control the device with adb while your minute budget runs.
QNN
Qualcomm Neural Network graph and runtime APIs within the deployment stack.
Quantization
Mapping float values to a small set of integer levels plus a scale per group. Cuts model size and memory traffic; adds rounding error.
Resident set size (RSS)
The physical memory a process holds. Peak RSS from getrusage is the largest value so far — it only grows during a process's lifetime.
RMSNorm
A normalization layer that rescales a vector by its root-mean-square, then multiplies by a learned weight. Qwen3 also applies it to each query and key head.
RoPE (rotary position embedding)
A way to encode token order by rotating query and key vectors by position-dependent angles. Only Q and K are rotated, never V.
Sampler
The rule that picks the next token from the model's output probabilities (temperature, top-k, top-p, seed). Runtime configuration, not part of the compiled graph.
Scale (quantization)
The float distance between integer levels, stored once per group. Symmetric max-based form: s = max(|w|) / qmax.
SpinQuant
A method that multiplies weights (and activations) by orthogonal rotation matrices before quantization. The rotations cancel mathematically but spread outliers, lowering quantization error. Qwen3 uses passes R2 and R3.
Split-head attention (SHA)
An attention rewrite where each head computes separately and the q/k/v/o projections become 1×1 convolutions carrying the original weights. Qualcomm applies it to Qwen3 through SHAQwen3Attention before export.
SSH tunnel
An ssh connection used only to forward a local port to a machine you cannot reach directly. -L makes a remote service look local; -N runs no remote command.
Static shape
A tensor dimension fixed to one integer in the graph itself, decided at export or compile time. NPU compilers need static shapes to plan memory and pick kernels ahead of time.
Symmetric quantization
Quantization with levels centered on zero, so no offset (zero point) is stored — only a scale per group.
Tied embeddings
Sharing one weight matrix between the input embedding and the LM head. Saves storing the largest matrix in the model twice.
Tokens per second (decode)
Generated tokens divided by generation time after the first token. The steady-state speed of the one-token decode graph plus its overhead.
Tracing
Exporting a model by running it once with example inputs and recording every tensor operation. Python control flow disappears; shapes freeze to the example.
TTFT (time to first token)
Milliseconds from sending the prompt to receiving the first generated token. Dominated by the prefill pass.
Unlike runtime paths
Measurements from different hardware, precision, or runtime stacks. They may be shown together with a warning but never averaged or ranked directly.
W4A16
Weights stored as 4-bit integers, activations quantized to 16-bit integers. The only published precision for Qwen3-0.6B on AI Hub at the pinned release.
Warm-up run
A first, discarded benchmark run that absorbs one-time costs such as memory allocation and shader compilation, keeping them out of the measured runs.
